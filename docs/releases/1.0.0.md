# Official Release Version 1

**Nocturne 1.0.0 · Release · Windows · Minecraft Java 26.1.2 · Fabric · client only**

Install Fabric Loader 0.20.1 or newer, the Fabric API build for 26.1.2, and Java 25. Put one Nocturne mod JAR in `mods`; do not install it on a server. Press **N** to run the setup checks.

## New mod features

- **Setup checks:** live desktop detection, lyric lookup and placement checks, with an explicitly labelled visual demo.
- **Music library:** search Spotify tracks, browse accessible playlists, play or queue a selected track and open it on Spotify. Desktop detection stays the default. Library access uses the optional account connection; reconnect existing accounts to grant playlist scopes. Spotify developer access, Premium and device restrictions apply.
- **Music-only audio:** capture the selected application's Windows process tree instead of the desktop mix. Supported automatic process mappings cover Spotify, Cider, Tidal, foobar2000, YouTube Music desktop and Chrome/Edge/Firefox. Multiple ambiguous roots or unknown identities produce a diagnostic and no capture. Browser capture includes other tabs in that browser. Playback on a different computer or phone cannot supply local PCM.
- **Real spectrum and tempo:** a 2048-point FFT produces 32 logarithmic frequency bands. Adjust bass, mid and treble response independently. Detected-beat pulses are optional; BPM is an estimate shown only after a consistent onset history.
- **Lyric-free visuals:** spectrum, signed waveform and three-band views, either between lyrics or throughout playback. No fake waveform or fallback tempo is generated when capture is unavailable.
- **Terrain visibility:** bounded raycasts detect scenery between the camera and the lyric anchor, with a readable edge caption fallback.
- **HUD avoidance:** reserve the hotbar, subtitle area and sidebar; add regions for minimaps and other overlays. Other mods can register dynamic exclusions through `HudAvoidance.register`. Arbitrary third-party drawing cannot be discovered automatically.
- **Controller text entry:** focus a Studio text field and press the controller's accept button to open the keyboard. Use D-pad left/right to move between characters and Tab actions to reach Space, Shift, Symbols and Use text. Cancel preserves the original value. Built-in controller polling yields to Controlify/MidnightControls.
- **Persistent album covers:** validated compressed thumbnails survive restarts. Disk cache expires after seven days and remains within 64 entries / 8 MiB; memory cache remains bounded separately.
- **Download management:** browse lyric/artwork entries by song label, age and size; select entries and confirm removal. Older lyric downloads without labels display their cache ID. Local lyric corrections, presets and tokens are preserved.
- **Guided editors:** four-step in-game instructions for lyric timing, theme design and world placement, with direct links to the actual tools.

## Controls

| Task | Open in Studio |
| --- | --- |
| Spectrum, waveform, frequency response and beat effects | Player → Music spectrum & beat effects |
| Track search and playlists | Player → Browse music library |
| Download storage | Health → Manage lyric & artwork downloads |
| Setup and tutorials | Health → Help & setup |
| Reserve space for another overlay | Place → Reserve space for other overlays |
| Toggle automatic HUD and terrain fallback behavior | Search settings → `Avoid HUD overlays` / `Terrain occlusion fallback` |

Capture and visualization stop while paused, minimized, unfocused, without matching local music, or under reduced-motion/photosensitivity controls. Windows process loopback requires build 20348 or later, including Windows 11. Lyrics remain subject to provider coverage and timing quality.

## Validation

Offline DSP tests cover frequency separation, silence, regular beat recovery, stale-frame rejection and a coarse processing budget. Cache tests cover restarts, expiry, bounds, corrupt/truncated files and selective deletion. A two-process Windows audio fixture verifies that a selected 440 Hz tone is captured while a separate 3200 Hz player is excluded, and that stopping clears the signal. Native Minecraft checks exercise setup, controller text entry, terrain obstruction, GUI scales, rendering, reload/reconnect and existing performance budgets. These checks do not imply every controller, account entitlement or player application has been tested.
