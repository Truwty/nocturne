# Nocturne 1.1.0-alpha.1 — Experience preview

Optional world, combat, cosmetic, movement and interface modules are bundled into the existing music mod. Minecraft **26.1.2**, **Fabric**, **Java 25**. This is a development preview; existing published releases are unchanged.

Open **O** for Orbit, **B** for emotes, **J** for visual blocks, or hold **C** to zoom. **N** continues to open music settings. New modules default to off/server appearance. All controls can be rebound.

Includes six color-grading shaders, local environment controls, seasonal tints, bounded particles and movement effects, observed combat effects, eight death styles, memory-only slow-motion replay, local procedural cosmetics and companions, animated texture packs/HD weather, container/session widgets, hotbar easing, visual toys and optional Discord IPC presence.

See the [complete feature guide](https://github.com/Truwty/nocturne/blob/feature/nocturne-experience-suite/docs/experience-suite.md) for exact capabilities and limitations. Blocks/cosmetics are local visuals. Chest previews contain only previously delivered inventory data. Combat attribution depends on health data exposed by the server. Replay does not stop the live world. Discord uses the official Nocturne application automatically when enabled; desktop Discord is required on Windows. Its live connection is not validated by the offline suite.

Validation: 225 offline tests passed and one optional live lyric-provider test skipped. The targeted Minecraft client checks pass locally, including real entity combat, shader loading, resource-pack reloads, replay, GUI scales and photosensitivity cleanup. Older compatibility ports and live multiplayer sessions have not been validated for this preview.
