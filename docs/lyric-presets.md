# Lyric presets

Open **N > Lyric presets**. Browse 57 built-in looks, filter by category, save favourites, or save a custom look. Selecting a style only changes the sample. Apply saves the settings; Apply & view also closes Studio so you can see the actual world lyrics. The visual demo is silent and explicitly labelled.

**Perfection** fixes the lyric anchor relative to the camera, including during turns and changes in pitch. It uses uniform lettering and removes motion decoration. It respects intentional screen hiding and accessibility locks; lyrics still require valid lyric data and source timing.

Search matches names, categories and descriptions. Export selected copies portable JSON to your clipboard. Import JSON validates the appearance fields and shows a sample before application. Custom names cannot overwrite built-ins. Undo/redo restores the complete applied appearance and placement. Per-song and context profiles can still override appearance in their configured situations.
