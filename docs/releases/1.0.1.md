# Nocturne 1.0.1 - reliability and polish

**Stable release - Windows - Minecraft Java 26.1.2 - Fabric - client only**

Install Java 25, Fabric Loader 0.20.1 or newer, and Fabric API for 26.1.2. Replace the existing Nocturne JAR; keep only one copy in `mods`. Desktop detection remains the default and needs no Spotify login.

## Changed in the mod

- Automatic lyric matching validates the exact endpoint as well as search results against title, artist, recording version and duration. Remasters, featured artists and browser titles are normalized; meaningful title parentheses and artist punctuation are preserved. Missing artist metadata prompts manual selection rather than guessing a recording.
- Manual search ranks likely recordings first. Each result opens a scrollable timestamped preview with metadata confidence and timing provenance. Cancel preserves the current lyrics; saving remembers the choice for that song across launches. A changed song cannot receive an old preview's selection.
- Recovery separates unavailable matches, provider/network failures, estimated timing and off-screen placement. Its actions open search, retry, timing editing, resynchronization or visibility restoration as appropriate. Intentional hiding does not reset placement.
- Playback compares samples at a shared timestamp, accepts small timing corrections and ignores older samples from the same session. Seeks, pause/resume, device switches and advertisement return reset the lyric clock correctly.
- Slow world-editor drags accumulate sub-step movement. A gesture remains one undo/redo operation, including when closing during a drag; Save retains it.
- Fresh installations use restrained karaoke animation, a readable backplate and fewer automatic effects. Existing saved preferences are retained. Advanced animations and effects remain available in Studio.
- Lyric downloads have bounded response bodies and shared per-provider cooldowns that respect HTTP Retry-After responses. Long preview documents submit only visible rows.

## Verification and limits

See [the reliability check report](../reliability-1.0.1.md) for the regression cases and measured client rendering results. Measurements concern Nocturne CPU submission work, not total game frame time or GPU performance. Synthetic crowded-scene and short soak checks are not an hours-long multiplayer benchmark. Lyric availability and timestamp quality depend on the provider; word karaoke still needs source word timestamps.
