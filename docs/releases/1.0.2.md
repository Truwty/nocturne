# Nocturne 1.0.2 - Lyric presets

**Official stable release - Windows - Minecraft 26.1.2 - Fabric - client only**

## New

- A dedicated **Lyric presets** tab in Studio.
- **57 built-in looks**, including Perfection and eight families: Focus, Cinema, Neon, Sky, Cloud, Motion, World and Retro. Looks combine placement, animation, typeface, line length, scale, lingering and bounded effects; they are not just palette swaps.
- **Perfection:** a fixed camera-relative anchor that follows movement and camera turns without trailing behind. Uniform word sizing, a readable backplate, no shake, zoom, orbit, drifting, particles or entrance animation. Lyric highlighting continues to follow the available source timestamps.
- A preset browser with search, categories, favourites, a style sample, Apply & view, a visual demo, custom saves, JSON import/export and undo/redo.
- Presets preserve playback connections, lyric timing, chat/inventory hiding, reduced-motion preferences and photosensitivity protection. Selecting or previewing a sample does not change your active look until Apply.
- Studio navigation now uses two rows so the full Lyric presets label stays readable.

This release also includes the lyric matching, recovery, saved-selection and synchronization fixes from 1.0.1.

## Install

Use Java 25, Fabric Loader 0.20.1+ and Fabric API for Minecraft 26.1.2. Replace the older Nocturne JAR and keep one copy in `mods`. Existing settings are preserved. Open **N > Lyric presets > Browse 57 lyric presets**. Choose **Perfection** and click **Apply & view** for the stable placement look.

Perfection controls appearance and placement; it cannot supply missing lyrics or improve inaccurate provider timestamps automatically. No server installation is required.
